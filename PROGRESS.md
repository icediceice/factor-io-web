## Current Focus

The AI inference TCO calculator is at **SPEC v0.3**: a pure calculator with no narrative, on **one screen** that recomputes as you type. Demand is derived from a user count rather than asserted as a token total, workloads are modelled as a chat/RAG/Graph RAG/agentic mix, sizing binds on the peak second, breakeven is reported as a whole number of months, and the three options are named (Self-hosted / Model API / Rented GPU) with the "Lane" vocabulary removed from every rendered surface. **Throughput is now DERIVED from the model** — size, context, attention architecture (full / sliding / GDN / MLA) and quantisation feed a decode bandwidth roofline that solves batch and tensor-parallel size, replacing v0.2's per-accelerator constant; that constant survives only as the fallback for cards with no published bandwidth. The serving-model presets are no longer hand-curated: stage 3/3 of the refresh command derives them from the Hugging Face Hub — ranked by `trendingScore` rather than lifetime downloads, with params taken from `safetensors.total`, layer groups tallied from `config.json:layer_types[]`, MoE active counts accepted only when the same geometry reproduces the published total within 2%, and every unmappable candidate recorded in `skipped[]` instead of dropped silently. Rented-GPU rates come from a per-provider registry refreshed by the same command, and each provider is sized on its own accelerator running the selected model. Remaining work is operational: evidence ingestion (which would also replace the `[ASSUMED]` efficiency constants with measurements), feed TTL calibration, and resolving the rented-vs-self-hosted billing asymmetry logged as a todo.
