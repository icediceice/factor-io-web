02 / Model-First GPU Auto-Sizing

2. เลือกโมเดล AI ที่ต้องการใช้ และรุ่นการ์ด GPU เพื่อคำนวณจำนวนเครื่องอัตโนมัติ

โมเดลและขนาด Context คือตัวกำหนด VRAM และความเร็วถอดรหัส ระบบจะเลือกโครงสร้างเซิร์ฟเวอร์และจำนวน GPU ที่รองรับได้จริงให้อัตโนมัติ

กำหนดพารามิเตอร์โมเดลเอง / ทดสอบความไวขนาดโมเดล (Custom B, Active B, BF16 KV bytes/tok) Catalog

สำหรับโมเดล Custom ต้องระบุทั้งพารามิเตอร์รวม, Active B, อัตรา KV Cache (BF16 bytes/token) และ Max Context เพื่อให้การคำนวณ VRAM ถูกต้องตามจริง

ตารางเปรียบเทียบจำนวนการ์ดและเซิร์ฟเวอร์อัตโนมัติในแต่ละรุ่น GPU
